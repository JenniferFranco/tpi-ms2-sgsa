# SGSA — Sistema de Gestión de Solicitudes Académicas (versión inicial)

TPI de Metodología de Sistemas II (UTN — TUPaD). Integrantes: Jennifer Franco y Jonathan Franco.

Aplicación de consola en Python para registrar estudiantes y solicitudes académicas, cambiar su estado, asignar responsables, buscar/filtrar y ver un reporte básico. Datos en `datos.json` (sintéticos).

```bash
python sistema.py
```

> Esta es la **versión inicial** del sistema (tag `estado-inicial`): funciona, pero fue escrita rápido y tiene problemas de diseño que se diagnostican y corrigen en las etapas siguientes.
